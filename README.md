# Elgeis Map data

The approved map data for the [Elgeis Map](https://github.com/chipthrasher/elgeis). Each folder is a layer: a `layer.json` manifest plus one GeoJSON file per object. The format is described in the map's [DESIGN.md](https://github.com/chipthrasher/elgeis/blob/main/DESIGN.md).

The map's backend is the only thing that should write here. Each approved change request becomes one commit, with the requester as author and the approving admin and change request ID in the message. To suggest a change, use the map.

This history before the README was split out of the `layers/` folder of the map's repo.
